# tenfold default key bindings (embedded into the binary; this file is the source).
#
# TODO(OPEN_QUESTIONS #1, VERIFY WITH USER): these are PLACEHOLDERS. The real defaults must mirror the user's
# 10x key map (KeyMappings.10x_settings); nothing below is claimed to be 10x's binding except where the plan
# (IMPLEMENTATION_PLAN B4) lists it. Do not add 10x bindings from memory.
#
# Format:  [context] chord [chord ...] = Command.Id [argument]
#   context  optional: global (default), editor, picker. editor/picker bindings beat global ones.
#   chords   Ctrl+K Ctrl+C = two strokes. Modifiers: Ctrl Shift Alt Super. Mouse4/Mouse5 = thumb buttons.
#   '#' starts a comment only at the start of a line; a command of '-' removes a binding from an earlier layer.
# User overrides: <config dir>/tenfold/keybindings.txt, then <workspace>/.tenfold/keybindings.txt.
