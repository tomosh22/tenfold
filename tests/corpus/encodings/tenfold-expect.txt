# encodings: line endings and byte encodings the anchors have to survive. include/ and src/ hold CRLF files (crlf.*), a CR-only
# file (cronly.*), UTF-8 files with a BOM whose first line carries anchors (bom.h, bom2.cpp: BOM + CRLF), Latin-1 files with
# non-ASCII in comments and strings before anchors (latin1.*), tabs before anchors (tabs.*), multi-byte characters before
# anchors on the same line (mb.*: UTF-8 bytes != UTF-16 units: emoji are 4 bytes and 2 units), non-ASCII identifiers
# (idents.*), mixed LF/CRLF and a last line without newline (mixed.*), U+2028 / U+0085 / form feed / vertical tab (seps.*).
# Anchor columns are byte offsets of the file as stored (docs/TESTING.md).
