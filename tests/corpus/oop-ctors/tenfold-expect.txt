# oop-ctors: constructors (default, explicit, delegating, copy, move, inherited with `using Base::Base`), destructors,
# conversion operators, enums vs enum classes with the same enumerators, bit-fields, unions, static members defined in a
# .cpp, nested / local classes with the same names (Node, get, size), range-for over a custom container.
# A click on the *type name* of `Widget(2)` / `new Widget(5)` / a mem-initializer calls a constructor; clangd answers the
# class. The user decided (W10-CHOOSE) to choose between the class and the constructor, so those lines check the whole
# list (`=`) and which entry the chooser selects (`default`).
